## Summary

- Implemented backend using C# with ASP.NET Core and Entity Framework.
- Designed normalized relational databases with MSSQL.
- Used ASP.NET Identity and JWT for secure user authentication and role management.
- Abstracted file storage operations using dependency injection and interfaces, allowing easy switching between providers (e.g., MinIO, Firebase).
- Implemented a direct-to-storage architecture via Presigned URLs, offloading heavy I/O operations from the API server to the client.
- Orchestrated a fully containerized environment (Frontend, Backend, Database, MinIO) using Docker Compose for environment parity.

## Overview

The Harmonii Music App is a dynamic full-stack project that enables users to discover, stream, and curate playlists of their favorite music. Built with React.js for the frontend and ASP.NET Core with Entity Framework and MSSQL for the backend, it incorporates strong user authentication and authorization mechanisms, including role-based access control.

Admin users can verify accounts, assign moderators, and manage users. Moderators are responsible for managing music content, while regular users enjoy streaming and playlist features. The platform is architected for scalability, utilizing containerization and decoupled storage mechanisms to handle media streaming efficiently.

Harmonii was the culmination of my internship at KoçSistem and served as a capstone for improving my backend development skills in C# with ASP.NET. It was a hands-on journey into relational database architecture, secure APIs, and scalable deployments. ## Key Features

- **User Roles & Access Control**: Role-based authentication system using ASP.NET Identity and JWT.
- **Playlist Creation & Music Streaming**: Users can stream audio files and organize them into personal playlists.
- **Admin & Moderator Panels**: Admins manage user accounts; moderators manage music content.
- **Storage Abstraction & Presigned URLs**: Audio file uploads are handled securely via short-lived Presigned URLs, allowing clients to upload directly to MinIO/Firebase. This architectural decision significantly reduces API server load, memory consumption, and bandwidth usage.
- **Containerized Infrastructure**: The entire application stack is dockerized, ensuring consistent behavior across local development and production environments.
- **Interactive Frontend UI**: Built with React and styled-components, featuring animations via Framer Motion.

## Technologies Used

- **Frontend**: React.js, React Router, Axios, Styled Components, Framer Motion
- **Backend**: ASP.NET Core, Entity Framework Core, MSSQL, ASP.NET Identity, JWT
- **Storage & Infrastructure**: Docker, Docker Compose, MinIO, Firebase Cloud Storage, Microsoft Azure (App Service, SQL Server, API Management, Application Insights)

## Challenges and Learnings

Authentication and authorization were complex, especially ensuring secure token handling using JWT and ASP.NET Identity. Audio streaming posed performance concerns, addressed initially by offloading media handling to Firebase, and later refined by implementing interface-driven local storage with MinIO and Presigned URLs to bypass the API entirely during file uploads. Designing a normalized, scalable relational database schema also took several iterations.

Integrating frontend-backend communication taught me the importance of concise and intuitive API design. I also developed a deeper understanding of Docker orchestration and how to maintain environment consistency.

## Outcome

Harmonii became a fully functional, end-to-end music streaming platform. It strengthened my backend capabilities and gave me practical experience in containerization, system design patterns, and scalable storage integration. The project validated my ability to architect and deliver real-world applications with distinct user roles, content moderation features, and optimized I/O operations.
