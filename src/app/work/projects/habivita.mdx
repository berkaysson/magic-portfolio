## Summary

- Developed a  full-stack multi-entity SaaS ecosystem for life-improvement platform with todos, tasks, habits, categories, projects, notes, charts-analytics and activity tracking.
- Integrated real-time logging and progress analytics using PostgreSQL, Prisma, and Supabase.
- Optimized expensive server-side aggregations and complex summary-progress calculations using **Next.js server side cache** for high-performance data retrieval.
- Achieved high code reliability by implementing **Unit Testing** for core business logic and helper modules using **Jest**, effectively reducing technical debt.
- Designed a high-fidelity, responsive interface using Shadcn UI and TailwindCSS, prioritizing visual hierarchy.

## Overview

Habivita is a personal journey companion designed to empower users in achieving their goals, improving productivity, and building lasting habits. It combines task management, activity logging, and habit tracking in one cohesive platform. With an intuitive dashboard and dynamic visualizations, Habivita offers a clear and insightful look into your progress across all dimensions of life.

## Key Features

- **Scalable Performance Analytics**: Utilizes server-side caching mechanisms to deliver instantaneous progress reports even with large datasets of logged activities.
- **Reliable Business Logic**: Core modules (notes, habits, and progress tracking) are backed by a comprehensive suite of unit tests to ensure consistent behavior during scaling.
- **Comprehensive Dashboard**: Provides a high-level overview of habits, tasks, and activities with charts and analytics.
- **Activity Logging**: Users can log time spent on any activity to gain insights and inform goal-setting.
- **Contextual Note-Taking**: Integrated rich-text note management linked to specific habits, todos or tasks via #mentions.

## Technologies Used

- **Frontend & Backend**:
  - **Next.js** (App Router, Server Actions)
  - **TypeScript**
  - **Tanstack Query** (Client-side state & caching)
  - **Jest** (Unit Testing)

- **Database & Hosting**:
  - **PostgreSQL** & **Prisma** (ORM)
  - **Supabase** (DB Hosting & Auth)
  - **Vercel** (Deployment & Serverless Functions)

- **Styling & UI**:
  - **TailwindCSS**, **Shadcn UI**, **Material UI**

## Challenges and Learnings

Building a unified system that tracks qualitative and quantitative data required strict architectural discipline. Implementing `unstable_cache` addressed performance bottlenecks in server-side rendering of analytics, while Jest was introduced to mitigate regression risks during rapid feature iterations.

Handling database schema design for flexible task types and visualizing time-based data pushed the boundaries of UI/UX and full-stack performance optimization.

## Outcome

Habivita evolved into a production-ready app that demonstrates mastery over modern Next.js patterns, performance tuning, and test-driven development (TDD) principles. It serves as a benchmark for building maintainable, high-performance SaaS applications.
